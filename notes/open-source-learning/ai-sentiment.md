# 从多智能体舆情系统学习复杂项目的最小切入点

> 学习笔记，不代表原项目归属。上游：[666ghj/BettaFish](https://github.com/666ghj/BettaFish)。

## 为什么收藏

我收藏 AI Sentiment，是为了理解一个包含 Query、Media、Insight、Report 与 Forum 多个 Agent 的公开信息分析系统，如何把检索、分析、报告和数据库连接拆分为可协作的模块。

## 如何使用／运行

上游提供 Docker Compose 和源码两条路径，但完整系统需要 Python 环境、数据库、浏览器驱动以及兼容的 LLM 配置。对于学习目的，不应直接配置真实密钥或启动大规模爬取；应从 README 提到的最小 demo、单个 Agent 或本地 mock 配置开始，使用公开且合规的数据。

## 解决什么问题

它提供多阶段研究与报告生成的工程参考，适合学习模块边界、配置管理、Agent 协作与最终报告生成之间的关系。

## 观察到的限制

系统依赖多、配置面广，并涉及公开信息采集与外部模型服务；数据合规、平台条款、成本、密钥管理和结论可靠性都需要独立评估，不能把自动生成的分析直接视为决策依据。

## 下一步微实验

不运行完整系统，先画出五个 Engine 的输入、输出和依赖图；随后用一份公开、少量、去敏的文本数据测试一个不联网的情感分类或摘要流程，再记录哪些配置是最小可行的。
