# 从教育资源集合学习来源标注与边界

> 学习笔记，不代表原项目归属。上游：[mswnlz/edu-knowlege](https://github.com/mswnlz/edu-knowlege)。

## 为什么收藏

我收藏 Learning Library，是为了研究教育资源集合如何按月份、主题和外部入口组织，以及当资源来自多个平台时，如何在个人学习记录中保留来源与使用边界。

## 如何使用／运行

这是资源目录型仓库，不需要启动程序。可以从 README 的月份索引与主题链接开始，优先查看原始公开来源和各自的授权说明；需要本地研究目录结构时，只下载必要的文档，而不是把资料集合当作可任意转载的内容库。

## 解决什么问题

它为“资料很多但找不到入口”的学习场景提供了一个导航结构，也让我能观察大规模链接集合的命名、分期和更新方式。

## 观察到的限制

README 中的上游仓库和资源站链接属于原始维护脉络；它们不应被改写为我的个人项目。资源可用性、版权和真实性也不能仅由目录保证。

## 下一步微实验

选一个主题制作自己的十条以内学习清单，每条只保留原始链接、用途、最后核验日期与授权备注；比较这种小而可核验的清单和大而宽泛的资源集合。
