# 从内容归档 CLI 学习授权与 Markdown 保存边界

> 学习笔记，不代表原项目归属。上游：[PhiFever/AfdianToMarkdown](https://github.com/PhiFever/AfdianToMarkdown)。

## 为什么收藏

我收藏 Content Archiver，是为了学习一个 Go 命令行工具如何把作者动态和作品集整理为 Markdown，并在 README 中明确说明它不能免费获取订阅后才能查看的内容。

## 如何使用／运行

上游 README 提供了 Go 构建、Release 可执行文件和 `motions`、`albums`、`update` 等命令入口。任何实际使用都只能针对自己拥有访问与保存权利的内容，并应遵循平台条款；本文不保存或分享认证材料，也不把浏览器会话数据写入笔记。

## 解决什么问题

它展示了“从在线内容到可检索 Markdown”的归档思路，适合研究命令设计、增量更新和不覆盖既有文件的策略。

## 观察到的限制

上游 README 明确限制受订阅保护内容；当前说明也提示图片支持和站点域名会随版本变化。认证、版权和平台规则是这类归档工具的核心限制，而不是应被绕过的障碍。

## 下一步微实验

不用真实平台内容，先对自己写的一组本地 Markdown 文件实现“只新增、不覆盖、记录更新时间”的小脚本，验证归档策略本身，再决定是否继续研究命令行同步设计。
